# Jatrio — Full-Stack Travel Community Platform

> **Real Trips. Real Costs. Real Stories.**  
> *Plan better with real travel experiences shared by real travelers.*  
> **বাস্তব ট্রিপ, বাস্তব খরচ, বাস্তব অভিজ্ঞতা।**

Jatrio is a mobile-first, bilingual travel community and trip-cost-sharing platform designed for Bangladesh and expandable worldwide. It allows real travelers to publish authentic trip itineraries, actual expense breakdowns, hotel reviews, route details, and safety tips, while empowering others to search, copy, split expenses, and plan custom journeys.

---

## 🌟 Key Features

- **Bilingual Interface:** Instant switching between English & Bangla (`/en`, `/bn`).
- **Multi-Step Trip Creator:** 8-step publishing wizard for transport, stay, food, activities, daily logs, and advice.
- **Detailed Cost Breakdown & Recharts Analytics:** Per-person & itemized cost visualizations.
- **Trip Copy & Personal Planner:** Copy any public trip into a private editable trip plan.
- **Group Trip & Expense Splitter:** Invite trip members, track group expenses, and calculate net settlements ("Who owes whom").
- **Dynamic Destination Engine:** Destination stats automatically calculated from user-submitted trips.
- **Shareable Trip Poster Exporter:** Generate downloadable social media graphic posters with QR codes and cost tags.
- **Community Q&A & Cost Confirmations:** Real-time question answering and community cost accuracy voting.
- **Programmatic SEO:** Clean route structures, OpenGraph tags, and JSON-LD schemas (`Article`, `FAQPage`).
- **Supabase Backend & Demo Mode:** Complete Postgres schema with Row Level Security (RLS) and automatic fallback to interactive demo data when unconfigured.

---

## 🚀 Quick Start

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Local Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Database Migration (Optional for production setup):**
   Execute SQL from `supabase/migrations/20260731000000_initial_schema.sql` in your Supabase SQL editor.
